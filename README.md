# 🍔 Food Delivery Data Analysis & Business Intelligence

## 📌 Project Overview

This project focuses on analyzing food delivery order data to understand customer behavior, restaurant performance, delivery efficiency, and business revenue.

The project uses Python for data cleaning and exploratory data analysis (EDA), SQL for database integration and data management, and Power BI for creating interactive dashboards and business insights.

The main objective is to transform raw food delivery data into meaningful insights that can help improve business performance and operational efficiency.

## 🎯 Project Objectives

- Analyze food delivery orders and customer purchasing patterns.
- Clean and preprocess raw datasets using Python.
- Identify factors affecting order cancellations and late deliveries.
- Evaluate restaurant performance and customer ratings.
- Analyze delivery partner performance and delivery times.
- Understand revenue, discounts, tips, and payment methods.
- Build interactive dashboards to visualize business insights.

## 🔄 Project Workflow

### 1. Data Collection
- Imported the original food delivery dataset.
- Explored dataset structure, columns, and data types.
- Identified missing values and duplicate records.

### 2. Data Cleaning Using Python
- Handled missing values.
- Checked duplicate records.
- Converted date and time columns into appropriate formats.
- Analyzed outliers using the IQR method.
- Validated categorical and numerical columns.
- Prepared the final cleaned dataset.

### 3. Exploratory Data Analysis (EDA)
Performed analysis on:
- Customer behavior and order patterns.
- Restaurant ratings and categories.
- Order values and payment methods.
- Delivery partner experience and ratings.
- Delivery times and traffic conditions.
- Weather conditions and cancellation rates.
- Discounts and tips.

### 4. SQL and Python Integration
- Connected Python with MySQL.
- Created the `FOOD_DELIVERY_DETAILS` table.
- Inserted cleaned data into MySQL in batches.
- Verified the number of records uploaded.

### 5. Power BI Dashboard

Created an interactive Power BI dashboard with seven analytical pages:

1. **Executive Overview** – Overall business performance and key KPIs.
2. **Customer Analytics** – Customer types, age groups, and order value.
3. **Restaurant Analytics** – Restaurant ratings, categories, and preparation time.
4. **Driver Analytics** – Driver experience, ratings, and delivery performance.
5. **Logistics & ETA** – Estimated delivery time, actual delivery time, traffic, and late deliveries.
6. **Financial Analysis** – Revenue, discounts, tips, and payment methods.
7. **Overall Data Overview** – Overall business metrics and operational insights.

## 📊 Key Business Insights

The project explores important business questions:

- Which cities generate more orders?
- Which restaurant categories contribute more order value?
- What factors influence order cancellations?
- How does weather affect delivery performance?
- Does traffic influence estimated and actual delivery times?
- How does driver experience relate to delivery performance?
